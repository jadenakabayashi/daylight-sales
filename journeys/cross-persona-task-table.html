Daylight Media — cross-persona research

Who does what, and with what

Key tasks and responsibilities by user type, grounded in stakeholder interviews — plus the tools, artifacts, and documents each task actually runs through today.

📎 Current-state, not aspirational. Every row below traces to a stakeholder interview (Brett Connaughton/Ad Ops, Thomas Mancusi/Sales, Jesse Tracy/Finance, Jay Green/Content Partnerships) or a Foundation doc. Where a system's real name is ambiguous across interviews (see the Marly/Molly/Bob/Bolt naming cluster), the persona's own words are used. Product, Legal, and Executive appear on the org roster but haven't been interviewed yet — no task detail exists for them beyond a title, so they're intentionally left off this table rather than guessed at.
Sales Thomas Mancusi · Level 4

Owns deal formation end-to-end — RFP intake through a signed IO, rate-setting, and the master rate card — then hands off to Ad Ops. A real Sales/Ad Ops alignment meeting (Brett, Ad Ops) confirmed this boundary directly: Sales owns everything through drafting/submitting the RFP; Ad Ops's part starts at vetting.

TaskResponsibilityTools / artifacts / docs
Rate card filtering Cross-references the Rate Card against a client's target list — competitive exclusivity, prior vetting responses, genre — before handing a candidate show list to Ad Ops for vetting. Daylight Media Roster.xlsx (manual copy/paste)
RFP drafting & agency templating Adapts the filtered show list into whichever template the agency uses (Oxford, RSU, WPP) — done ~95% of the time by Aaron Hurting. OR RFP Template.xlsx + agency templates
Ad-load judgment (at close) Approves/declines a new booking against an unwritten mental rule (max 3 embedded spots/show/week) before it's handed to Ad Ops for scheduling. Memory only (no tool) + Molly / Bob view
IO intake & papering handoff Receives signed Insertion Orders by email and hands off to Ad Ops for order entry. Email (IO handoff)
Rate / CPM decisions Sets, holds, or raises CPM weekly from 8-week trailing/forward sellout %. Molly sellout dashboards
Master List / Rate Card ownership Solely owns and edits the full rate card weekly — demos, CPM, exclusivity history, attribution vendor per show. Daylight Media Roster.xlsx
Delivery / performance monitoring Checks over/under-delivery per episode to inform CPM decisions — a distinct read of Podscribe from Ad Ops's delivery-issue use of the same tool. Podscribe
Renewal & win-back outreach Tracks flight end dates and cancellations from memory to time re-engagement. Memory only (no tool)
Prospecting & new-brand pricing Evaluates a new advertiser's fit for a show using average-unit-rate reasoning. Daylight Media Roster.xlsx
Ad-placement doctrine Personal IP taught verbally to hosts — spot length, position, spacing rules. Taught verbally (no tool)
Ad Ops Brett Connaughton · Level 2

Everything downstream of a signed IO — vetting, order entry, ad-plan scheduling, copy trafficking, revisions, and delivery reporting. Per Brett: "sales doesn't really need visibility into a lot of this" once a deal is placed.

TaskResponsibilityTools / artifacts / docs
Vetting Sends vetting requests on the Sales-supplied show list, logs yes/no + reason — the first task in Ad Ops' hand-off (Sales does not execute vetting itself). Marly Advertisers page
Ad plan & scheduling (BOB) Builds the week-over-week ad-plan grid — spot spacing, midroll rotation, category exclusivity (manual rules, no system enforcement). Marly / QCode Ad Plan (BOB)
Order entry ("papering") Manually re-enters each IO spot-by-spot into the order system — the single biggest time sink. Marly / QCode · order naming: {order#}_{advertiser}_{agency}_{date}
Flight / schedule revisions Manually moves a booked flight to a new week — copy all fields out, delete, re-enter, repeated per affected spot. Marly / Vault ad-plan grid
Ad copy trafficking Monday "copy audit" + Wednesday follow-up emails to advertisers missing a recorded script. Marly / Vault Copy Upload tab · email
Pre-approval tracking Flags clients requiring script pre-approval; a checkbox triggers an automated reminder. Marly / Vault ad-plan checkbox
Revisions & make-goods Tracks underdelivery make-goods against a raw email thread; not a living document. Email thread · Dynamic Order (Marly)
Delivery reporting & performance tracking Cross-references sales-order data against delivery data — two disconnected tabs, manual CSV comparison. Podscribe + Marly (manual CSV)
Client (weekly) reporting Manual pull, sanity check, and send of performance data to clients. Podscribe exports
Finance Jesse Tracy · Level 3

Invoicing, collections, payouts, and per-show financial reporting across ~100 shows.

TaskResponsibilityTools / artifacts / docs
Monthly invoice generation Generates the prior month's invoices, split by revenue type rather than combined. Marly Finance (Generate Invoice / Bill / Social / Custom / Usage / Rewards)
Billing-destination management Chooses whether an order bills the advertiser or agency; hand-builds workarounds for dual-billing cases. Marly Advertiser/Agency tab
Collections / past-due tracking Monitors unpaid/past-due invoices, sends (often batched) reminder emails. Marly invoice list · email
PDF invoice retrieval Pulls sent-invoice PDFs to attach to collections follow-ups. Bill.com
Monthly per-show financial reporting Manually populates and publishes a PDF report per show, monthly — the top-cited pain point. External accountant's Excel files → manual entry → PDF
Payout reporting Runs Gross Revenue / Daylight Participation / Show Participation splits per show. Marly Finance Payout Reports
Miscellaneous revenue tracking Tracks non-core revenue outside Marly, still being built out. Financial Airtable (parser tool)
Internal metrics reporting Exports raw Marly data and manually pivots it — no native pivot-table export. Marly export → Excel monetization sheet
Broadcast-month reconciliation Manually reconciles clients on a broadcast-month cycle against Marly's calendar-month default. Marly Finance / Bill.com
Content Partnerships Jay Green · Level 4

Owns the show/host relationship — onboarding, custom sponsorship builds, one-sheets, and partner-facing reporting.

TaskResponsibilityTools / artifacts / docs
Show onboarding Collects show and host surveys from talent/producers to populate the system before launch. Emailed surveys → Marly
Vetting & partner-performance tracking Tracks vetting responses and a partner-responsiveness checklist. Marly
Billing/invoicing oversight Monitors partner billing to spot invoicing gaps and reports back to partners. Marly
Weekly booking reporting Every Monday, manually pulls the prior week's bookings to notify partners of closed revenue. Marly order system → Excel pivot table
Custom sponsorship package development Builds/tracks non-standard packages — segment/studio/tour sponsorships, host-specific brand asks. Custom master sheet · Daylight Custom Opportunities sheet · Canva
One-sheet creation & distribution Produces per-show marketing one-sheets sent to advertisers. Canva → PDF on Google Drive
Ad plan updates Requests changes to a show's ad plan — requires product-team approval today. Marly (via product-team sign-off)
Host detail tracking Tracks granular host info (preferences, special asks) with no unified system. Disparate manual documents
